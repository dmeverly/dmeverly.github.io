Shift Schedule Generator

Upload or paste a shift-rotation template to generate a 12-month schedule plus an individual schedule for each employee. The data is read and processed entirely in your browser — nothing is uploaded to a server. The tool detects the header row, shift columns, and week count automatically, so small layout changes shouldn't need a site update.

Need a starting point? Download a blank template, fill in employee names per week, then upload it above. You can add more shift columns (label + 7 day-of-week columns, any order) or more week rows later — the tool re-reads the layout from the file each time.
